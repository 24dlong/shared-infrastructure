# shared-infrastructure

Shared AWS foundation for the Next.js infrastructure initiative.

This repository currently manages only:

- Terraform remote state bucket bootstrap
- GitHub Actions OIDC provider
- Repo-scoped IAM roles for plan/apply

## Layout

- `bootstrap/`: reusable, one-time-per-environment creation of that
  environment's own S3 state bucket.
- `infra/`: the single Terraform root applied to every environment (OIDC
  provider and IAM roles). One copy of the code, applied N times with
  different inputs — never copied per environment.
- `environments/<env>/`: per-environment docs and the `deployed.json`
  desired-state file that drives that environment's plan/apply pipeline.

See [ARCHITECTURE.md](./ARCHITECTURE.md) for the full multi-environment
model, how deploys are triggered, and how to add a new environment.

## Consuming this foundation's outputs

Application infrastructure (e.g. repos generated by `cookiecutter-nextjs-infra`)
should never hardcode this account's state bucket name, region, or OIDC
provider ARN. Instead, read them dynamically via a `terraform_remote_state`
data source pointed at this repo's production state:

```hcl
data "terraform_remote_state" "foundation" {
  backend = "s3"
  config = {
    bucket = "24dlong-shared-infrastructure-prod-terraform-state"
    key    = "shared-infrastructure/production/terraform.tfstate"
    region = "us-east-2"
  }
}

# example usage
module "github_oidc" {
  source = "git::https://github.com/24dlong/terraform-modules-library.git//modules/github-oidc?ref=<tag>"

  create_oidc_provider    = false
  github_oidc_provider_arn = data.terraform_remote_state.foundation.outputs.github_oidc_provider_arn

  tags = merge(data.terraform_remote_state.foundation.outputs.tags, { App = "my-app" })

  # ...
}
```

**Currently published outputs** (see `infra/outputs.tf` for the source
of truth):

| Output | Description |
| --- | --- |
| `state_bucket_name` | Shared Terraform state bucket name. |
| `state_bucket_region` | Region of the shared state bucket (`us-east-2`). |
| `github_oidc_provider_arn` | ARN of the account's single GitHub Actions OIDC provider — reuse via `create_oidc_provider = false`, never create a second one. |
| `shared_infrastructure_deploy_role_arn` / `_name` | This repo's own apply role (not generally useful to other consumers). |
| `shared_infrastructure_plan_role_arn` / `_name` | This repo's own read-only plan role (not generally useful to other consumers). |
| `tags` | Common tags map to merge into consumer resources. |

**This list only grows.** Future shared resources (Route 53 hosted zone, ACM
certificate, a VPC, etc.) get added here as new outputs when they're built —
existing output names and meanings never change, so anything already
consuming this contract keeps working without modification. Always read by
output name; don't assume this table is exhaustive.
